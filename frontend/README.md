# Easy Learn frontend

Static HTML, CSS, and JavaScript prototype. Open `index.html` in a browser.

- `index.html`, `about.html`, `services.html`, `contact.html` — main pages
- `subjects.html` — shared four-subject picker for practice tests, vocabulary, and concepts
- `typing.html` — progressive typing levels and timed practice preview
- `css/` — shared design, readability, and learning-path styles
- `js/app.js` — shared navigation, theme, flashcards, FAQ chat, and typing interactions
- `assets/logo.jpg` — Easy Learn logo

The contact form is a visual prototype. The subject picker and typing progress use browser-side behavior and are not yet connected to an account or backend.
